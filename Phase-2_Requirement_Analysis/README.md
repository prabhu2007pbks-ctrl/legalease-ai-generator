# Phase 2: Requirement Analysis Phase

## Functional Requirements
- User interface to select legal document type (Rental Agreement, NDA, Affidavit).
- Text fields to capture dynamic user details.
- Integration with Google Gemini API to generate structured legal text.
- Preview and copy functionality for the generated document.

## Non-Functional Requirements
- Response time under 10 seconds.
- Simple and easy-to-use user interface.
- Secure handling of Gemini API Key.

## Software Requirements
- Python 3.10+
- Streamlit
- google-genai SDK
