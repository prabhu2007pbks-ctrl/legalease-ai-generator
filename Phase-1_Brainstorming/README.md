# Phase 1: Brainstorming & Ideation Phase

## Project Title
Legal Ease: AI-Powered Legal Document Generator

## Problem Statement
Drafting legal documents (like rental agreements, NDAs, and affidavits) manually takes a lot of time, requires legal expertise, and can be expensive.

## Proposed Solution
An AI-powered web application using Google Gemini API and Streamlit that automatically generates accurate, customizable legal documents based on simple user inputs.
